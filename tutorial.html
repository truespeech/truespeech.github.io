Learn truespeech

truespeech is a small, SQL-like language for asking a semantic layer questions — and, crucially, for capturing what an analyst knows about the data alongside the data itself. This page introduces the core ideas, then walks the language feature by feature in cells you can run and edit. Want to just tinker? Head to the sandbox. Need the exact grammar? See the reference.
